# Windows AI 输入助手

基于 WinUI 3 的独立 Windows AI 输入助手，面向 Windows 10/11 x64，使用 DeepSeek 官方接口提供短文本续写。

## 当前阶段

已完成需求确认与仓库初始化。尚未实现应用程序，暂无可运行版本或安装包。下一步形成软件工程技术方案并验证关键系统接口。

## 已确认的产品行为

- 用户只需填写 API Key，接口地址与模型选择由软件管理。
- 停顿 1.5 秒后生成一条约 20～60 个中文字符的续写建议；默认读取光标前后各 300 字符。
- 每条建议均需用户手动确认插入；采纳后默认继续生成下一条。
- 启动和电脑解锁后默认暂停，通过快捷键启用后全局生效，排除密码框。
- 支持快捷键截取当前输入窗口所在显示器，并用于一次生成。
- 浮窗仅在有建议时显示，不抢输入焦点，记住位置、大小、背景透明度和字号。
- 截图为一次性临时数据，上传后删除，不持续保留为上下文；正文和截图不写入日志。

以上为产品要求，具体应用兼容范围与截图处理实现须通过技术验证。

## 默认快捷键

| 快捷键 | 功能 |
| --- | --- |
| Ctrl+Alt+Space | 启用／暂停 |
| Ctrl+Alt+S | 截取当前输入窗口所在显示器并生成 |
| Ctrl+Alt+Enter | 在光标处插入当前建议 |
