# v1.1 实现与验证记录

## 输入框兼容性

传统 Win32 Edit 控件优先使用带超时的原生消息读取文本和光标；过滤密码、只读、禁用和选区状态，校验焦点、窗口、进程生命周期、光标位置及文本指纹。输入通过 Unicode SendInput 完成，并回读确认，仍不使用剪贴板。原生读取范围最多 1 MiB，长文只向模型发送光标前后各 300 字符。

其他控件使用 UI Automation。浏览器输入框归属按辅助功能树核对，支持控件与前台窗口分属不同进程。对缺少可选接口或事件的提供者使用选择范围、可编辑属性和内容回读。

不再按中文键盘布局直接阻止工作。TextEdit 活动组合范围以及可取得的 IMM 组合串用于检测输入法状态；IMM 跨进程查询为尽力而为。某些输入法候选窗口未公开状态时，停顿与内容复核无法证明组合输入已结束；此类场景仍需实测。每条插入仍需用户确认。

## 窗口与图标

设置页关闭时取消销毁并最小化，维持任务栏入口。胶囊使用无激活分层窗口，空闲时显示状态，有建议时展开。拖动胶囊保存位置，建议展开后可调整尺寸。背景透明度沿用外观设置；双击打开设置，右键可切换和退出。应用、任务栏、托盘、安装器采用同一 ICO。

## 更新

UpdateClient 与 DeepSeek 使用独立 HttpClient，只访问固定仓库的最新正式 Release；不发送 API Key。校验版本、附件名、下载地址、状态、大小和 SHA-256，下载使用临时文件并在完整验证后改名，取消和失败清理临时文件。自动检查在启动 20 秒后及每 6 小时进行，可关闭，也支持手动检查。下载完成后用户点击“重启并安装”。

独立 UpdateHost 复制到下载暂存目录后运行，再次锁定并校验安装包，发送就绪标记，等待原进程退出后启动 Inno Setup。成功后确认文件版本并重新打开应用。安装不自动重启 Windows，重启需求写入状态文件。配置、密钥、日志均在独立用户数据目录保留。便携目录通过此流程安装后会增加卸载程序。

## 自动化验证

测试代码包括更新下载故障、缓存复用及取消处理；Win32 长短文本、密码、只读、选区、RichTextBox 与中文布局；Edge 普通输入、多行输入和 contenteditable；设置页最小化及恢复、常驻胶囊启动；更新器握手、等待进程退出、真实安装和用户配置保留。通过结果以对应 GitHub Actions 运行记录为准。中文布局测试不等同于真实候选词输入测试。

Word、WPS、微信及其他自绘控件没有在当前环境实际运行；Windows 10/11 桌面、多 DPI、真实中文候选状态与 DeepSeek 调用仍需用户环境验证。
