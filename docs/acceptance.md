## 4. 核心行为

| 编号 | 用例 | 通过标准 |
| --- | --- | --- |
| F01 | 启动、重启、解锁 | 均暂停；无自动正文读取、截图和生成请求 |
| F02 | 启用／暂停快捷键 | 切换一次，托盘状态正确；暂停后旧响应不能复活 |
| F03 | 连续键入和停顿 | 只在最后相关输入后 1.5 秒触发；没有每键请求 |
| F04 | 光标位于开头、结尾、段中 | before／after 边界正确，各最多 300 文本元素 |
| F05 | emoji、代理对、组合字符、中英混合 | 截取和插入不破坏字符；内容不乱码 |
| F06 | 非空选区、多重选区、只读控件 | 不生成可采纳建议，不覆盖所选正文 |
| F07 | 中文拼音长时间停在候选阶段 | 不因 1.5 秒超时而发请求；上屏后重新计时 |
| F08 | 微软拼音及一种第三方中文输入法 | 组合识别、快捷键释放、采纳无串键；分别记录版本 |
| F09 | 采纳建议 | 只插入一次，光标位置正确，已有后文保留 |
| F10 | 采纳后自动下一条 | 插入回读成功后只生成一条；未确认不再插入 |
| F11 | 无输入继续静止 | 不为同一上下文不断计费；空结果不重发 |
| F12 | 浮窗出现、拖拽、缩放、隐藏 | 输入窗口持续拥有键盘焦点；设置持久化 |
| F13 | 100／150／200% DPI、负坐标副屏、跨屏窗口 | 浮窗可见、大小合理；截图选屏规则一致 |
| F14 | 屏幕拔插、睡眠恢复 | 浮窗回到可见区域；恢复后暂停 |
| F15 | 三个快捷键分别被占用 | 指明冲突并允许修改；不显示虚假的已启用状态 |
| F16 | 建议生成失败 | 没有空白／错误正文浮窗；状态信息可在托盘或设置看到 |

## 5. 竞态与插入阻断项

| 编号 | 注入场景 | 通过标准 |
| --- | --- | --- |
| R01 | 请求 A 慢、B 快；A 在 B 后返回 | 只展示匹配当前 revision 的 B |
| R02 | 生成时切换应用／移动光标／删除文字 | 旧建议立即失效；不会进入新窗口 |
| R03 | 两处具有相同前后文本，光标在两处切换 | 使用目标和 range 身份区分，不能只比较文本散列 |
| R04 | 采纳键按下后、释放前切窗 | 取消插入；不主动激活原窗口 |
| R05 | 采纳时按住 Ctrl／Alt 或组合输入开始 | 等待释放或拒绝；不发送意外快捷键 |
| R06 | 连按／长按采纳快捷键 | 当前建议只 consume 一次 |
| R07 | SendInput 部分返回、文本未出现、回读超时 | 标为 Uncertain；不重发、不回滚、不继续生成 |
| R08 | API 取消后仍返回完整结果 | 被 epoch／revision 检查丢弃 |
| R09 | ContextHost UIA 调用永久阻塞 | UI 可响应，超时清理、有限重启；不泄漏工作线程 |
| R10 | 生成／插入前锁屏；解锁后旧请求完成 | 保持暂停；旧请求无效 |
| R11 | provider 事件延迟或漏发 | 展示和采纳时复核仍能拒绝陈旧建议 |
| R12 | 目标进程退出后 HWND 被复用 | 进程启动身份和 ContextHost token 失效 |
| R13 | 插入后用户立即继续键入 | 不把用户输入当注入回声吞掉，不误判后再次插入 |

R01～R13 任一出现错误目标插入、重复插入或破坏原文，即阻断发布。为时间竞争设置随机延迟和重复执行，各支持控件至少执行 100 次焦点竞争场景；零次观察失败只证明该测试范围，不声称消除了系统原子性限制。

## 6. 模型接口与输出

| 编号 | 用例 | 通过标准 |
| --- | --- | --- |
| A01 | 请求构造 | 固定官方域名；Key 仅在 Authorization；思考模式显式关闭 |
| A02 | 401、余额不足、429、5xx、DNS 失败 | 正确分类，无无限重试；冷却生效 |
| A03 | SSE 跨字节拆分、空帧、keep-alive、错误帧、断流 | 不乱码、不展示半条；只有有效完成结果可采纳 |
| A04 | 文本与图片请求超时 | 分别遵守 15／30 秒期限并释放资源 |
| A05 | 拒绝、空输出、输出过长、工具调用、finish_reason=length | 按策略丢弃或安全取完整分句，不静默插入残片 |
| A06 | 输入／图片中存在改变任务的指令 | 只生成待确认文字，不触发任何系统操作或工具 |
| A07 | 非英文与专业术语、句中插入、已有后文 | 人工评估自然衔接、无重复、无生硬扩写 |
| A08 | 真实 DeepSeek 文本和图片请求 | 各验证成功响应及 token 用量；记录耗时，不保存敏感负载 |

质量集采用至少 60 条独立合成样本，各类至少 10 条；人工记录可用／需改／不可用及原因。目标至少 90% 满足格式与长度策略，至少 80% 可直接采纳；这是验收目标，不是已达到的指标。模型别名变化后重跑质量集。

## 7. 截图和隐私

| 编号 | 用例 | 通过标准 |
| --- | --- | --- |
| P01 | 焦点在密码框或密码属性不可判定 | 不读取文本、不截图、不请求、不插入 |
| P02 | 暂停状态按截图键 | 仅生成一次；完成和采纳后仍暂停，不连续生成 |
| P03 | 单屏、双屏、跨屏输入窗口 | 截取输入窗口所属屏，覆盖范围与界面说明一致 |
| P04 | 建议窗当前显示 | 截图不包含建议窗；不因隐藏／恢复改变输入焦点 |
| P05 | 截图完成后切目标 | 清理缓冲，丢弃请求，不向新目标展示／插入 |
| P06 | 上传成功、异常、取消、超时 | 所有自有图像缓冲释放；无图像文件、日志或下一轮复用 |
| P07 | 采纳截图建议后继续生成 | 下一请求没有图片或图片摘要；仅有新文本上下文 |
| P08 | 4K／超宽屏、黑帧／受保护内容 | 遵守本地大小预算，失败可理解；不冒称捕获成功 |
| P09 | 合成敏感文本／Key 出现在请求、响应、异常中 | 搜索日志和导出包均无匹配，正文散列也不记录 |
| P10 | API Key 保存与配置迁移 | 磁盘无明文 Key；导出无 Key 密文；其他用户不可直接解密 |
| P11 | 外部进程连接 IPC／协议超长 | 不接受未授权会话；拒绝异常包 |
| P12 | 程序退出／ContextHost 重启 | 不恢复上次正文、建议或截图，始终暂停启动 |

P01 是密码输入目标保护；全显示器截图中其他窗口的内容不自动识别遮盖，不能把 P01 写成“截图里永远没有敏感信息”。

## 8. 性能与发布记录

用固定合成负载记录 p50／p95、峰值内存和异常样本。云端耗时和本地调度耗时分开，不能以模拟服务延迟代替实际响应体验。资源指标按主进程与 ContextHost 合计。

发布前必须覆盖：干净系统启动、设置保存、连续使用 30 分钟、50 次启用暂停、50 次锁屏恢复、UIA 子进程重启、安装／覆盖安装／卸载、无管理员权限运行。API Key 不随构建产物分发。
