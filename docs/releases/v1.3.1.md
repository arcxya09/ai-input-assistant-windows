# AI 输入助手 v1.3.1

修复 v1.3.0 续写异常及过严的上下文判断。

- SSE 的 `tool_calls: null` 和空数组按未调用工具处理；真实工具调用仍拒绝。兼容结束帧的 `delta: null` 及用量帧。
- 短语、未完成句子和短选区均可尝试续写，不再因字数少直接判定信息不足。
- JSON 中额外元数据不展示；只提取明确成功的正文，重复关键字段、失败说明、无效 JSON 和不完整响应仍拒绝。
- 文本接口暂未就绪时最多重读两次；读取失败与模型认为信息不足分别提示。日志只增加固定阶段代码、模式和字符数，不记录原文或模型正文。
- 修复 Obsidian 跨段落选区超出焦点段落范围而误报“目标变化”：向上定位所属文本容器，保持焦点、选区和前台复核。增加多段落正向、反向选区和采纳复制验证。
- 辅助功能接口可能将 Markdown 段落间的多余空行表示为单个段落分隔符；选区上下文保留接口返回的全部正文，不自行补齐 Markdown 空行。

安装版：`AiInputAssistant-1.3.1-Setup-x64.exe`。现有版本也可通过设置页检查更新。
