# AI 输入助手 v1.2.0

本版修复续写被裁短、状态浮窗过大和设置窗口不能完全隐藏到后台的问题。

- 从光标前后文直接衔接，补全光标所在词句；没有后文时写到当前段落自然收束，有后文时接回已有内容。保留英文连接所需的首尾空格，并拦截明显重复上下文的建议。
- 取消 20～60 字目标及 60 字裁剪，扩大生成与插入容量。只展示完整结束的响应；服务达到上限或中断时整条拒绝并提示，不插入截断内容。
- 半透明状态胶囊高度约 30 DIP，宽度随状态文字变化。长建议按内容展开，超过屏幕可用范围时支持滚轮及右键翻页；采纳始终使用完整建议。
- 点击设置窗口关闭按钮后隐藏到后台，从任务栏和 Alt+Tab 列表移除，托盘和胶囊继续运行。双击托盘或胶囊恢复设置，右键菜单“退出”彻底关闭程序。
- 保留 GitHub 自动检查下载、设置和密钥保存、应用图标及已有输入框兼容性改进。

## 下载与更新

- `AiInputAssistant-1.2.0-Setup-x64.exe`：安装版，直接运行。
- `AiInputAssistant-1.2.0-win-x64.zip`：便携版，完整解压后运行 AiInputAssistant.exe。
- `SHA256SUMS.txt`：校验值。

v1.1 用户可在程序中“检查更新”，下载完成后选择“重启并安装”；设置和密钥保留。v1.0 用户需手动安装本版。

## 实现边界

单次请求预算为 4096 tokens、90 秒，最多接收 8192 个 UTF-16 单元。这些是资源保护上限，达到上限不会裁剪插入。建议为单段文字，避免向聊天输入框注入 Enter。模型实际表达和跨应用兼容性仍需用户环境验证；本次未使用真实 DeepSeek API Key 发起付费调用。
