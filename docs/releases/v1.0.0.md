# AI 输入助手 v1.0.0

Windows 10 1809+ / Windows 11 x64。首次启动填写 DeepSeek 官方 API Key 即可使用。

## 下载与安装

- **AiInputAssistant-1.0.0-Setup-x64.exe**：安装版，按当前用户安装。
- **AiInputAssistant-1.0.0-win-x64.zip**：便携版，完整解压后运行 AiInputAssistant.exe；请保留同目录文件。
- **SHA256SUMS.txt**：安装包与便携包的 SHA-256 校验值。

程序已包含所需运行时。安装包尚未进行数字签名。

## 主要功能

- WinUI 3 设置界面、托盘和不抢焦点的建议浮窗。
- 输入停顿约 1.5 秒生成一条短续写，默认读取光标前后各 300 字符。
- 每条建议需手动采纳；插入确认后可继续生成下一条。
- 单次截取当前输入窗口所在显示器，截图上传后清理。
- 软件启动、电脑解锁或恢复后暂停；排除密码输入框。
- 保存浮窗位置、尺寸、透明度、字号和快捷键。
- API Key 使用 Windows 当前用户加密保护；诊断日志不记录正文、截图和密钥。

## 默认快捷键

| 快捷键 | 功能 |
| --- | --- |
| Ctrl+Alt+Space | 启用／暂停 |
| Ctrl+Alt+S | 截图并单次生成 |
| Ctrl+Alt+Enter | 采纳当前建议 |
