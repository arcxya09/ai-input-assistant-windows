# 产品需求基线

确认日期：2026-09-17  
状态：需求问答已完成；工程实现与验收方案尚需制定。

## 1. 产品定位与平台

独立 Windows AI 输入助手，为当前输入位置提供短续写建议。

- 界面框架：WinUI 3。
- 支持平台：Windows 10/11 x64。
- 服务：DeepSeek 官方接口。
- 配置方式：用户只需填写 API Key，不要求填写接口地址或模型名。

Windows 10 的具体最低版本、SDK、运行时版本和分发方式在技术方案中确定。

## 2. 文本上下文与生成

- 默认读取光标前 300 字符、光标后 300 字符作为上下文。
- 输入停顿 1.5 秒后触发生成。
- 每次只生成一条建议，长度约为 20～60 个中文字符。
- 建议由用户逐条确认插入。
- 采纳后默认连续生成下一条，仍须用户确认。

跨应用上下文读取、输入法组合输入识别、光标变更检测与失效建议取消策略在技术方案中明确。

## 3. 启用与暂停

- 软件启动后默认暂停。
- 电脑解锁后默认暂停。
- 用户通过快捷键手动启用后，全局生效。
- 不采用应用白名单。
- 排除密码框。

无法可靠识别输入目标或无法读取上下文时的处理方式需要在工程方案中定义并验证。

## 4. 截图辅助生成

- 默认快捷键：Ctrl+Alt+S。
- 截取当前输入窗口所在显示器，并用于本次生成。
- 截图为一次性临时数据，上传后即删除。
- 不将截图保存为持续上下文。
- 不将截图内容写入日志。

截图处理链路、服务端图像输入能力、失败或取消时的临时数据清理方式需要技术验证。此需求不代表已经确认 DeepSeek 官方接口具备所需图像能力；如需调整产品方案，应单独说明。

## 5. 建议浮窗

- 仅在有建议时显示。
- 不抢输入焦点。
- 允许调整并记住位置、大小、背景透明度和字号。
- 使用快捷键在当前光标位置插入建议。

显示器切换、DPI 缩放、输入窗口变化与插入目标一致性需要覆盖兼容性验证。

## 6. 默认快捷键

| 快捷键 | 功能 |
| --- | --- |
| Ctrl+Alt+Space | 启用／暂停 |
| Ctrl+Alt+S | 截取当前输入窗口所在显示器并生成 |
| Ctrl+Alt+Enter | 在光标处插入当前建议 |

快捷键冲突的检测与提示方式在工程方案中确定。

## 7. 数据与日志

- 正文和截图不写入日志。
- 截图仅服务一次请求，上传后删除，不长期保留。
- API Key 的本地安全存储方式、请求取消与超时、诊断日志字段在工程方案中确定。
