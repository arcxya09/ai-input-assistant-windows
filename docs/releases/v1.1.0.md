# AI 输入助手 v1.1.0

本次集中改善输入框兼容性和常驻使用体验，并新增 GitHub 更新功能。

- 增加传统 Windows Edit 输入框的原生读取；改进 UI Automation 的光标、可编辑属性、辅助功能树和可选接口处理，适配浏览器的跨进程控件。
- 取消仅因中文键盘布局且缺少 TextEdit 接口而拒绝工作的限制；保留密码、只读、文本选择和插入前后复核。中文候选窗口的特殊行为仍需实际应用验证。
- 增加常驻半透明胶囊，显示暂停、已启用、已识别内容、正在续写和建议就绪等状态；有建议时展开，双击打开设置，右键启用／暂停或退出。
- 增加程序、任务栏、托盘和安装包图标；关闭设置页后最小化到任务栏。
- 默认启动后及每 6 小时检查 GitHub 最新正式版，自动下载并校验安装包；点击“重启并安装”后退出、安装并重新启动，保留设置与 API Key。支持手动检查和取消下载。

## 下载

- `AiInputAssistant-1.1.0-Setup-x64.exe`：安装版，直接运行。
- `AiInputAssistant-1.1.0-win-x64.zip`：便携版，完整解压后运行 AiInputAssistant.exe。
- `SHA256SUMS.txt`：校验值。

v1.0 没有更新器，需手动安装本版一次。便携版通过更新器安装后会在原目录增加卸载程序。

## 验证范围

自动化测试覆盖更新版本比较、元数据校验、下载与缓存、损坏／截断／取消处理；真实 Windows 输入框及 Edge 普通、多行和可编辑网页控件；密码与只读拦截；任务栏最小化／恢复、胶囊启动；更新器等待父进程退出、实际安装和配置保留。Windows 10/11 用户环境、Word／WPS／微信和中文输入法候选状态仍需实测。未使用真实 DeepSeek API Key 发起付费测试。
