# AI 输入助手 1.4 使用说明

## 安装与启动

运行 AiInputAssistant-1.4.1-Setup-x64.exe。也可以完整解压 portable ZIP 后运行 AiInputAssistant.exe；不要只复制单个 EXE，主程序需要旁边的运行时、PRI 和 ContextHost 目录。

面向 Windows 10 1809+ / Windows 11 x64。安装程序按当前用户安装，应用不要求管理员权限。安装包尚无数字签名。

启动后打开设置，填写 DeepSeek 官方 API Key 并保存。模型和地址已内置。软件每次启动、电脑解锁与恢复后均暂停。

## 输入续写

1. 将光标放到目标应用的可编辑输入框。
2. Ctrl+Alt+Space 启用；再次按下暂停。
3. 正常输入，停顿约 1.5 秒后会请求一段完整续写。
4. 建议浮窗显示后按 Ctrl+Alt+Enter 插入。
5. 插入确认后继续生成下一条；每条仍需手动采纳。

光标前后各读取最多 300 字符。没有后文时续写到当前段落自然收束，有后文时补充光标处缺失内容并接回原文。取消 60 字裁剪，英文连接空格保留；服务返回未完成内容时整条丢弃并提示，避免插入半句话。继续输入、切换窗口或移动光标会使旧建议失效。有选区时进入下述选区模式。

## 选区续写与复制

启用后用鼠标或键盘选中一段文字，停止操作约 1.5 秒后生成。模型只接收选中文字，以选区末尾为起点接着写；选区外文字和截图不作为上下文。

浮窗会显示“复制续写到剪贴板”。按 Ctrl+Alt+Enter 后，复制新增内容，不替换或删除原文，也不自动粘贴。随后可在需要的位置 Ctrl+V。复制后不会针对同一选区连续生成，重新选择或输入后再触发。

支持单个连续选区，最多 8192 个 UTF-16 单元（通常汉字占 1 个，部分表情占 2 个或更多）；超限会提示缩小选区，不截取其中一部分。选区改变会使旧建议失效。可读取的只读文本支持选区模式，密码框除外。

## 续写失败提示

模型以结构化格式报告续写成功或失败。上下文不足、无法续写、空结果、返回格式异常或请求中断时，胶囊只显示简短状态；不把道歉、错误说明或原始 JSON 当作正文，不插入或复制。常见的假成功说明也会被拦截。可调整内容或选区后重新触发。

## 截图辅助

Ctrl+Alt+S 截取当前输入窗口所在显示器，发送给 DeepSeek 进行一次生成。有选区时优先执行选区续写，不截图。没有选区时，截图包括该屏幕上其他可见窗口。图片仅在内存中处理，上传后清理，后续请求不会携带之前的图片。

截图快捷键仅在启用后生效。密码目标、无法确定输入位置或组合输入状态时不截图。

## 浮窗与托盘

浮窗不抢键盘焦点。拖动窗口可移动，建议展开时右下角可缩放。设置中可调整字号、背景透明度和三组快捷键。位置和大小保存到当前用户配置。

关闭设置页会隐藏到后台，移出任务栏和 Alt+Tab 列表，托盘继续运行，胶囊仅在启用时显示。双击托盘图标可以恢复设置。启用时显示半透明状态胶囊，默认字号下高度约 31 DIP（随 Windows 缩放），尺寸根据字号和状态调整。无建议时显示简短状态，右键菜单可查看完整状态；有建议时按正文长度展开，过长内容用滚轮或右键“上一页建议／下一页建议”翻阅。采纳会插入完整建议，不受预览范围影响。双击胶囊打开设置，右键可启用／暂停或退出。托盘菜单也可检查更新。

## 暂不支持的场景

应用必须能提供可编辑文本、准确光标及必要的输入法状态。某些自绘输入框、终端、远程桌面内的控件，可能无法处理。中文输入法不再因缺少 TextEdit 接口而直接被拒绝；可检测到组合输入时暂停，其他情况通过输入停顿、光标和内容复核降低误操作。候选窗口的跨应用兼容性仍需实测。管理员窗口和系统安全桌面不在支持范围。

插入结果不确定时会暂停，避免重复输入。请先查看目标框中的实际文字，不要反复采纳同一条。

正式的跨应用、Windows 10 和真实 DeepSeek 请求测试结果见仓库验证记录；构建通过不代表所有应用已通过验收。

## 诊断

设置页可以导出 ZIP 日志。不包含正文、截图或 API Key。配置位于当前用户 LocalAppData/AiInputAssistant；密钥使用 Windows 当前用户保护机制加密。日志仅记录固定事件代码与异常类型，不自动上传。

## 软件更新

默认启动 20 秒后检查 GitHub 最新正式版，运行期间每 6 小时检查一次，并自动下载新版。可在设置中关闭自动检查与下载，也可手动“检查更新”。下载期间显示进度，支持取消。

下载完成后点击“重启并安装”。更新器再次校验 SHA-256，等当前程序完全退出后在原目录安装，并重新打开程序。设置、密钥和日志保存在用户配置目录，更新时保留。不会自动重启 Windows；若安装要求系统重启，会记录提示供下次启动查看。

网络失败、GitHub 限流、文件缺失或校验不符时不会运行安装包。仅接受本仓库的正式 Release、x64 安装包和完整 SHA-256。安装包当前未作数字签名，校验值用于核对下载完整性。

便携版使用此功能后会在原目录增加卸载程序。v1.0 没有内置更新器，需要手动安装一次 v1.3。


## v1.4 思考与浮窗

未开启、暂停、锁屏或保存设置后，状态浮窗隐藏，托盘图标保留。先启用，再使用普通续写或截图快捷键。

在设置中选择“思考深度”，选择后自动保存并暂停：自动（默认）使用 DeepSeek 服务的默认思考策略，Max 显式请求最高思考强度，不思考直接生成。自动和 Max 使用服务默认生成预算，为思考保留空间；分别等待最多 5 分钟和 15 分钟，不思考最多 90 秒。继续输入、切换目标或暂停会取消当前请求。达到时间或资源上限时整条提示失败，不截断插入。只提取最终正文，思考内容不展示、不复制、不写入日志。

“统一字号”同时调整状态、续写正文和操作提示，默认 14；浮窗随字号和状态调整尺寸。透明背景上的文字采用灰度抗锯齿和高分辨率缩小绘制。


v1.4.1 首次显示前先按目标显示器 DPI 计算尺寸，避免高分屏首帧过小。旧配置原默认字号 16 会升级为 14，其他字号保留；升级后仍可自行调回 16 或其他字号。
