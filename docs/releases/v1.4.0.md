# AI 输入助手 v1.4.0

- 启动、暂停、锁屏后隐藏浮窗，托盘常驻；旧建议和延迟状态不会重新弹出。截图快捷键在启用后使用。
- 状态、正文及底部提示统一字号，按 DPI 与字号调整布局，采用预乘透明度、高分辨率绘制和平滑缩放改善文字边缘。
- 新增自动（默认）、Max 深度、不思考三个选项，选择后保存。旧配置升级默认使用自动，保留其他设置。
- 自动使用服务默认思考策略，Max 显式请求最高强度；思考模式采用服务默认生成预算，避免思考占满原来的正文预算。Max 通常耗时和用量更多。
- 思考内容与最终正文分离，长思考流不会套用正文长度限制；取消、过期响应、失败状态、完整段落及选区复制规则继续有效。

接口依据：[DeepSeek 官方参数说明](https://api-docs.deepseek.com/api/create-chat-completion/)。接口没有 auto 参数，自动模式不传 reasoning_effort；Max 传 max，不思考传 none。
