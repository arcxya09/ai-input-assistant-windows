# AI 输入助手 v1.3.0

本版增加选区续写，改进 Obsidian / Electron 编辑器的光标识别，并将续写失败转为状态提示。

- 补充 Chromium 辅助功能唤醒、深层编辑器定位、折叠选区光标回退及 IAccessible2 文本读取。读取和超时控制继续放在独立进程中，不修改全局屏幕阅读器设置，也不注入目标进程。
- 选中文字后只以该选区作为生成上下文，从选区末尾继续写；不附带选区外的前后文或截图。
- 选区模式下，按 Ctrl+Alt+Enter（或自定义采纳键）复制新增内容到剪贴板，不替换原文、不自动粘贴。浮窗明确显示复制操作，复制成功后停止针对同一选区连续生成。
- 复制前复核选区和目标窗口；选区改变后旧结果失效。可读取的只读文本支持选区模式；密码框继续拒绝读取。
- 光标和选区使用专用提示词与 JSON 成功／失败协议；上下文不足、无法续写、空结果或格式异常时只显示程序内状态，不展示模型说明、原始 JSON，也不插入或复制。
- 无选区时继续使用原有的光标续写、快捷键原位插入、完整段落、半透明胶囊和后台运行功能。

## 下载与使用

- `AiInputAssistant-1.3.0-Setup-x64.exe`：安装版。
- `AiInputAssistant-1.3.0-win-x64.zip`：便携版，完整解压后运行主程序。
- `SHA256SUMS.txt`：校验值。

v1.1 及以上版本可在软件中检查更新，下载完成后重启安装；设置和 API Key 保留。

启用后选中文字，停顿约 1.5 秒等待建议，再按 Ctrl+Alt+Enter 复制。随后可自行 Ctrl+V 粘贴。选区支持一个连续范围，最多 8192 个 UTF-16 单元；超限时提示缩小范围，不截取其中一部分。仅选中文字用于生成，截图快捷键在有选区时也优先执行选区续写。

## 兼容性边界

本版通过 Windows 辅助功能接口读取当前编辑器。其他 Obsidian 版本、主题、插件及中文输入法候选状态仍需用户环境验证；无法读取的控件会提示，不通过模拟全选或临时覆盖剪贴板获取正文。未使用真实 DeepSeek API Key 发起付费测试。

实现参考：[Electron 辅助功能说明](https://www.electronjs.org/docs/latest/tutorial/accessibility)、[Chromium 辅助技术检测](https://www.chromium.org/developers/design-documents/accessibility/)、[IAccessible2 文本接口](https://github.com/LinuxA11y/IAccessible2/blob/master/api/AccessibleText.idl)。
