# 开发路线

当前阶段：仓库初始化。以下任务尚未实施。

## 第一阶段：软件工程技术方案

- 确定工程结构、模块边界、依赖与 Windows 最低支持版本。
- 设计暂停、启用、等待输入停顿、生成、展示与采纳的状态转换。
- 确定上下文读取、输入目标识别、密码框排除与文本插入方式。
- 验证 DeepSeek 官方接口当前能力，确定文本与截图请求链路。
- 设计 API Key 存储、一次性截图清理、错误处理与无正文日志。
- 制定跨应用、Windows 10/11、多显示器和输入法兼容性验收清单。

## 第二阶段：关键能力验证

- 验证常用输入控件中的光标上下文读取与正确插入。
- 验证全局快捷键、无焦点浮窗与中文输入法组合输入处理。
- 验证锁屏／解锁后的暂停状态和密码框排除。
- 验证截图处理可行性及取消、失败时的清理行为。

## 第三阶段：最小可用版本

- 实现 API Key 设置、文本续写、建议展示与逐条采纳。
- 实现采纳后继续生成、陈旧请求取消与建议失效处理。
- 实现浮窗外观与位置设置持久化。
- 按已验证方案接入一次性截图辅助生成。

## 第四阶段：兼容性与交付

- 完成 Windows 10/11 x64 的实际运行验证。
- 完成目标应用、输入法、多显示器与 DPI 验证。
- 完成诊断、打包、使用说明和版本发布准备。

实现进展和验证结果随代码一同提交；通过对应验证后再标记完成。
