# AI 输入助手 v1.4.1

- 浮窗默认字号从 16 调整到 14，状态、正文和操作提示保持统一；默认胶囊高度约 31 DIP，随 Windows 缩放。
- 修复首次出现时按 96 DPI 绘制导致高分屏上浮窗过小的问题：先创建隐藏窗口并读取目标显示器 DPI，再计算尺寸、绘制并显示。
- 显示器缩放变化时重新计算文字与胶囊尺寸，避免叠加框架自动缩放；继续保持不抢焦点、暂停隐藏和状态自适应。
- 旧配置中的原默认字号 16 升级为 14，其他字号保留；升级后手动选择 16 也会正常保存。

## 验证范围

Windows 构建包含五档字号和 100%／125%／150%／200%／250% DPI 的首帧、重复显示、暂停恢复及 DPI 消息往返检查，并输出合成样图。DPI 测试替换显示器 DPI 查询，窗口创建、布局、绘制和显示均走真实窗口代码；不能替代实体高分屏与混合缩放多显示器的实际验收。

保留核心、原生 Windows、Edge、Obsidian、剪贴板和更新安装回归。构建与发布结果将在验证完成后记录。

实现依据：[Microsoft GetDpiForWindow](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getdpiforwindow) 与 [WM_DPICHANGED](https://learn.microsoft.com/en-us/windows/win32/hidpi/wm-dpichanged)。
