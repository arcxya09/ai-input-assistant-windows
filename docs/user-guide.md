# AI 输入助手 1.0 使用说明

## 安装与启动

运行 AiInputAssistant-1.0.0-Setup-x64.exe。也可以完整解压 portable ZIP 后运行 AiInputAssistant.exe；不要只复制单个 EXE，主程序需要旁边的运行时、PRI 和 ContextHost 目录。

面向 Windows 10 1809+ / Windows 11 x64。安装程序按当前用户安装，应用不要求管理员权限。安装包尚无数字签名。

启动后打开设置，填写 DeepSeek 官方 API Key 并保存。模型和地址已内置。软件每次启动、电脑解锁与恢复后均暂停。

## 输入续写

1. 将光标放到目标应用的可编辑输入框。
2. Ctrl+Alt+Space 启用；再次按下暂停。
3. 正常输入，停顿约 1.5 秒后会请求一条短续写。
4. 建议浮窗显示后按 Ctrl+Alt+Enter 插入。
5. 插入确认后继续生成下一条；每条仍需手动采纳。

光标前后各读取最多 300 字符。建议通常 20～60 字符。继续输入、切换窗口或移动光标会使旧建议失效。没有选中内容时才允许插入。

## 截图辅助

Ctrl+Alt+S 截取当前输入窗口所在显示器，发送给 DeepSeek 进行一次生成。截图包括该屏幕上其他可见窗口。图片仅在内存中处理，上传后清理，后续请求不会携带之前的图片。

暂停时也可手动生成一次；采纳后仍暂停。密码目标、无法确定输入位置或组合输入状态时不截图。

## 浮窗与托盘

浮窗不抢键盘焦点。拖动窗口可移动，右下角可缩放。设置中可调整字号、背景透明度和三组快捷键。位置和大小保存到当前用户配置。

关闭设置页后仍驻留系统托盘。托盘菜单可打开设置、启用／暂停或退出。

## 暂不支持的场景

应用必须能提供可编辑文本、准确光标及必要的输入法状态。某些自绘输入框、终端、远程桌面内的控件，以及不能检测中文组合输入的控件会拒绝自动处理。管理员窗口和系统安全桌面不在支持范围。

插入结果不确定时会暂停，避免重复输入。请先查看目标框中的实际文字，不要反复采纳同一条。

正式的跨应用、Windows 10 和真实 DeepSeek 请求测试结果见仓库验证记录；构建通过不代表所有应用已通过验收。

## 诊断

设置页可以导出 ZIP 日志。不包含正文、截图或 API Key。配置位于当前用户 LocalAppData/AiInputAssistant；密钥使用 Windows 当前用户保护机制加密。日志仅记录固定事件代码与异常类型，不自动上传。
