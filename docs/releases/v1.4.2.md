# AI 输入助手 v1.4.2

- 修复组合输入检测失败后不再复查导致的“等待选词”停滞；等待期间约每 750 毫秒重读，暂停或切换目标会取消等待。不会在仍有明确组合输入时按超时放行。
- UIA 组合范围须包含文字、处于当前文档并关联当前光标或选区，忽略其他位置遗留的组合范围；原生 IMM 检测继续保留。
- 自动思考对文本使用 low，对截图使用 high，不因上下文字数多而提高强度。Max、不思考仍显式保留；思考模式继续使用服务默认生成预算，不用缩小总 token 上限来提速。
- 重写续写提示词：充分展开相关内容再收束，避免长原文只得到空泛总结；有后文时优先衔接，允许短补全。输入选区与完整正文不裁剪。
- 状态浮窗显示等待响应、思考、生成正文和耗时；明确区分达到输出上限与普通中断，失败仍只显示状态。
- 增加不含正文的生成诊断，包括耗时、首个正文分片、字符数、结束原因和 token 用量。

## 验证

构建与回归结果将在验证完成后记录。真实付费模型的延迟和内容质量、用户所用输入法与具体文本框仍需实机确认。

接口依据：[DeepSeek 请求参数](https://api-docs.deepseek.com/api/create-chat-completion/)：支持 none／low／high／max，默认 high；思考模式默认生成预算为 64K，Max 为 128K。low 控制思考强度，不保证固定响应时间。
